# Gambler's Fallacy — Research and Architecture Index

**Status: proposed architecture and research protocols; no empirical results or operational capabilities claimed verified.**

**Mission:** Build a UAF v1.7-governed, simulation-first AI Gambling Intelligence Laboratory (AGIL) to investigate whether AI distinguishes randomness from useful prediction, how memory/reward/feedback affect decisions, and whether the results generalize to system and process intelligence.

Read [governance](../governance/PROJECT_RULES.md), [thesis and experiments](RESEARCH.md), [architecture](ARCHITECTURE.md), [verification](VERIFICATION.md), [JEV assessment](JEV.md), and [roadmap](ROADMAP.md).

**Architectural authority:** UAF-001 v1.7 dated 2026-11-09 was supplied as a *proposed normative baseline*, not an approved implemented system. AGIL specializes its 16 perspectives, five mandatory foundation gates, control loop, AgencyGraph, EventGraph, CausalGraph, EvidenceGraph, AnnotationGraph, Broadcast and Playback. No additional top-level perspective is implied.

**Absolute design distinction:** schema validity ≠ semantic truth ≠ logically consistent knowledge ≠ correct execution ≠ functional result ≠ useful outcome ≠ established causal explanation. Independent claim-specific evidence is mandatory.

**Engineering:** GitHub is primary source history; GitLab and Codex are optional engineering aids, Python/SciPy candidate execution engines, GNU Octave/R/GSL independent numerical analysis candidates, and JEV a replaceable decision classifier. No integration is implied to exist.

**Scope:** experiments use virtual gambling environments, not autonomous real-money wagering. All proposed claims are hypotheses until separately verified.

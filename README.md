# Gambler's Fallacy — AI Decision Intelligence Research

**AGIL (AI Gambling Intelligence Laboratory)** is a proposed simulation-first experimental system for understanding how AI estimates probabilities, forms beliefs, selects actions, and adapts under uncertainty. The first research domain is the Gambler's Fallacy; the broader ambition is evidence-driven systems and process intelligence.

**Project status:** Architecture and experiment documentation only. No simulation, JEV decision, scientific validation, Broadcast/Playback runtime, or UAF foundation gate is claimed verified.

## Mandatory project rules

1. **GF-ARCH-001 — Broadcast everything meaningful:** authoritative, access-controlled, traceable events for all significant managed activity and state changes.
2. **GF-ARCH-002 — Playback-native visualization:** reconstruct and visualize complex adaptive behavior and patterns from recorded evidence, distinguishing history, re-execution and counterfactuals.
3. **GF-ARCH-003 — Every established claim must be proven by verified evidence:** preserve independent evaluation, provenance, scope, methods, uncertainty and negative findings.
4. **GF-ARCH-004 — Conformance does not imply correct outcome:** structural, semantic, functional, outcome and causal claims require separate checks.
5. **GF-ARCH-004-LC — Logical consistency:** evaluate contextualized claims and rules for contradictions using checkable methods and evidence.

These are approved project design requirements, **not yet implemented technical enforcement**.

## Foundation

The reference architecture is the user-supplied **Universal Architecture Framework, UAF-001 v1.7 (9 November 2026)**, currently a proposed normative baseline pending formal approval, executable contracts and acceptance evidence. AGIL specializes UAF's 16 perspectives, shared identity, graph semantics, enterprise seven-stage control loop, agency, verification, Broadcast and Playback. It does not invent a competing governance framework.

## Research integrity

Fair European roulette, under independent fixed-probability assumptions, has P(next red) = 18/37 no matter the previous streak. A winning virtual bet cannot by itself prove predictive skill. A schema-valid decision can still be semantically wrong; formal logic establishes the possibility, while a real JEV-specific error requires live evidence. Hypotheses, simulations, unsupported claims and inconclusive tests must always be labeled as such.

**Research only:** Initial scope uses virtual environments and virtual bankrolls. No autonomous real-money gambling.
